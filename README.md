# Justin DeMatteis Main Site

Standalone frontend for **justindematteis.com / JUST INNOVATE.**

## Architecture

- React + Vite
- Public content loaded from the shared Supabase CMS
- Site key is fixed to `justindematteis`
- Existing Website Admin continues to manage pages, Global Styles, header/footer and blog content
- Vercel SPA routing via `vercel.json`

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
